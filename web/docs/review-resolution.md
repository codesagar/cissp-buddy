# Independent review resolution

Claude Code Opus 5 reviewed the proposed architecture and then six implementation excerpts. The review was static, with no browser or runtime claims. GPT-5.6 Luna agents authored and cross-checked the taxonomy, learning design and question metadata; the owning agent integrated and validated all changes.

- Subtopic practice: already handled at the app boundary by filtering `metadata.subtopicIds` before the shared selector. Added explicit empty-scope feedback and automated coverage for every subtopic/domain pool. The review did not include the app boundary.
- Sticky hints: fixed the embedded check to preserve use after hiding a hint. Scored practice already records sticky assistance; assisted successes remain due and are excluded from the summary's correct-without-hints count.
- Release validation: already invoked by `release-pack.ts`, which was outside the excerpts. Added a mandatory prebuild check and bounded immutable manifest cache. Runtime installation remains an idempotent atomic first-read transaction for this pilot; local D1 cold seeding, repeated seeding, counts, foreign keys and query filters were exercised. Invalid releases fail clearly and never partially install. At larger scale, promote installation to a dedicated authenticated publishing step and load content in bounded slices.
- Visual grammar: card items now have stable IDs and validated links; decision emphasis is authored in the record; timelines show all outgoing labels. Misnamed matrices were reclassified as comparisons. The genuine risk matrix keeps its dedicated renderer. Extracted the original ten lead visual datasets from components into the database-backed learning design.
- Root coverage and sources: validation now requires an article for every graph root and parseable HTTPS reference URLs. Cross-root question tags remain permitted intentionally: scenarios can test an adjacent foundational concept. Tags were independently reconciled against the canonical taxonomy.
- Historical imports: retained strict non-destructive validation rather than silently dropping learner records as suggested. Releases are explicitly additive; database guards reject missing historical concept/question IDs and changed question semantics under a reused ID. Snapshots preserve original explanation text. Renames/deletions/merges require a future explicit migration and are not supported implicitly.
- Graph responsiveness: traversal results, visible IDs and hidden relationships are memoized across pan updates. Typed peer links contribute to hidden connection counts, and selecting a hidden connection reveals the hidden endpoint. Stable coordinates are tested for every branch and leaf.

Verification boundary: automated state/content/graph tests, TypeScript, lint, production build and HTTP/database checks. Browser visual, pointer, keyboard and device QA was not performed because browser testing was not requested. The site remains an AI source-checked pilot, not an expert-reviewed or complete exam curriculum.
